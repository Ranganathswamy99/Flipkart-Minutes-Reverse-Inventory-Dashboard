📊 Flipkart Minutes – Reverse Inventory & Warehouse Transfer Dashboard
🚀 Project Overview

This project focuses on analyzing reverse inventory flow in quick commerce operations. The dashboard tracks how returned items move from stores back to the source warehouse (hub).

🎯 Objective

To monitor and optimize the reverse logistics process by identifying bottlenecks in:

Return creation

Picking pendency

Dispatch readiness

Final dispatch

📦 Business Use Case

In operations like Flipkart Minutes, items are returned due to:

Damaged products

Expired inventory

Store exchanges

This dashboard helps track and improve reverse supply chain efficiency.

📊 Key Metrics

Total Return Quantity

Picking Pending Quantity

Waiting for Dispatch

Dispatched Quantity

Dispatch Efficiency (%)

📈 Dashboard Features

📍 City-wise performance analysis

🗺️ Interactive map with tooltips

⏳ Ageing bucket analysis (<2, 2–5, 5–10 days)

🔻 Funnel view (Return → Picking → Dispatch)

📊 KPI cards for quick insights

🧠 Key Insights

High return volume observed in major cities

Picking delays identified as key bottleneck

Ageing >10 days indicates operational inefficiency

Dispatch rate varies significantly across locations

🛠️ Tools Used

Power BI

DAX (Data Analysis Expressions)

Excel (Data Cleaning & Transformation)
